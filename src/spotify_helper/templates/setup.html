One-time setup

This tool needs its own Spotify app so it can read and edit your playlists.

  1. Go to developer.spotify.com/dashboard and create an app (any name; tick “Web API”).
  2. Add this exact Redirect URI: {{ redirect_uri }}
  3. Under User Management, add the email of your Spotify account.
  4. Copy .env.example to .env and paste the app's Client ID into SPOTIFY_CLIENT_ID.
  5. Restart the app and reload this page.

Spotify requires the app owner to have Premium for development-mode apps.
