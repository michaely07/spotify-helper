Split by genre: one-time setup

Spotify doesn't give apps genre data, so this tool uses Last.fm's listener tags.

  1. Create a free API account at last.fm/api/account/create (any app name; the callback URL can be left blank).
  2. Copy the API key into .env as LASTFM_API_KEY=…
  3. Restart the app.
